# 组队邀请页面（好友/推荐）设计

日期：2026-08-12
状态：已批准

## 背景

游戏「向僵尸开炮」新增组队邀请入口：寰球救援页和战斗页存在「邀请」按钮，点击后进入组队邀请弹窗页面，包含「推荐」「好友」两个 tab。

现有 `src/model/Game.ts`（废弃代码，引用已删除的 `../pages/public`）曾包含 `page_组队邀请_好友.click_邀请(teammate)` 自动邀请逻辑，本次不复活该逻辑，仅搭页面对象与路由，为未来自动邀请功能打基础。

## 范围

本次只做：两个页面对象 + 入口路由 + 注册。**不做**邀请动作方法、不复活 Game.ts、不加入日常任务流程。

## 设计

### 1. 新文件 `src/pages/组队邀请-好友.ts`

继承 `BasePage`，无路由出口（返回靠 Router 的 back）：

```ts
import { BasePage, Route } from './BasePage'
import { createPageDetector } from '../utils/img'

export class 组队邀请-好友 extends BasePage {
  name = '组队邀请-好友'
  is = createPageDetector('images/组队邀请-好友_1_0.9_409_2065_495_2103.png')
  routes(): Route[] { return [] }
}
```

### 2. 新文件 `src/pages/组队邀请-推荐.ts`

继承 `BasePage`，推荐 → 好友单向 tab 跳转（无「好友 → 推荐」按钮模板，故仅单向；反向由 back 处理）：

```ts
import { BasePage, Route } from './BasePage'
import { createPageDetector, createRouteAction } from '../utils/img'
import { 组队邀请-好友 } from './组队邀请-好友'

export class 组队邀请-推荐 extends BasePage {
  name = '组队邀请-推荐'
  is = createPageDetector('images/组队邀请-推荐_1_0.9_160_2059_252_2111.png')
  routes(): Route[] {
    return [
      { target: 组队邀请-好友, action: createRouteAction('images/组队邀请-推荐$组队邀请-好友_1_0.9_409_2065_495_2103.png'), imagePath: 'images/组队邀请-推荐$组队邀请-好友_1_0.9_409_2065_495_2103.png' },
    ]
  }
}
```

### 3. 入口路由（两处）

`src/pages/战斗.ts` 与 `src/pages/寰球救援.ts` 的 `routes()` 各增加一条（导入 `组队邀请-推荐`）：

```ts
{ target: 组队邀请-推荐, action: createRouteAction('images/$邀请_0_0.9_806_1641_892_1686.png'), imagePath: 'images/$邀请_0_0.9_806_1641_892_1686.png' },
```

`$邀请` 不带 `_`，按命名约定仅作点击按钮，不作页面识别。

### 4. 注册：`src/main.ts` 模块级

Router 的 `detectCurrentPage` / `findPath` 依赖页面实例注册，不注册则导航必失败。注册 ≠ 加入日常任务流程（daily.ts 的 nav 列表不含新页面，日常流程零影响）。

```ts
import { 组队邀请-好友 } from './pages/组队邀请-好友'
import { 组队邀请-推荐 } from './pages/组队邀请-推荐'
...
new 组队邀请-好友()
new 组队邀请-推荐()
```

main.ts 模块级执行晚于 daily.ts（静态 import 先执行），此时注册回调已设置，直接注册成功。注册顺序靠后，识别优先级最低，不与现有页面抢识别。

### 5. 不动

- `src/model/daily.ts`：不新增注册（用户要求日常任务不加入）
- `src/model/Game.ts`：废弃代码，不碰

## 错误处理与边界

- 战斗页/寰球救援页若无「邀请」按钮（入口未开放），Router 执行路径时按钮未找到，按现有机制回退重试后抛 `NavigationError`，行为与其他页面一致
- 组队邀请页若是弹窗而非全屏页面，战斗页识别图可能残留，与现有弹窗页面（如选择技能）情况相同，依赖 Router 既有 tryCloseModals 机制，不做额外处理
- 「好友 → 推荐」无按钮模板，不配路由；从好友页离开靠 back 返回战斗/寰球救援
