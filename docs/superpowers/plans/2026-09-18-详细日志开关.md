# 详细日志开关 实现计划

> **面向 AI 代理的工作者：** 必需子技能：使用 superpowers:subagent-driven-development（推荐）或 superpowers:executing-plans 逐任务实现此计划。步骤使用复选框（`- [ ]`）语法来跟踪进度。

**目标：** 设置页新增「详细日志」开关，勾选后本次运行的日志持久化到设备文件，供事后排查问题。

**架构：** 复用 AutoJs6 官方 `console.setGlobalLogConfig`（log4j 全局日志落盘），约 200 处既有 `log()`/`console.*` 调用零改动自动落盘。配置逻辑收敛到新文件 `src/utils/logger.ts` 的 `setupDetailLog(enabled)`；`src/main.ts` 的 `start()`（覆盖全部任务入口）开头调用一次。开关状态由现有 `PrefSwitch` 基类自动持久化（`storages.create("pref")`），无需额外代码。

**技术栈：** TypeScript（ES5/Rhino 兼容：禁箭头函数/const/解构）、webpack。

**验证方式：** 功能依赖 AutoJs6 运行时 API（`console.setGlobalLogConfig`、`files`），无法在 Node 侧单测。每个任务用 `npm run build` 验证编译；最终用真机诊断脚本 `dist/详细日志诊断.js` 验证落盘/复位行为（项目既有惯例：`test/*.ts` + webpack entry + 真机运行贴日志）。

**提交约定：** 每任务的 commit 步骤，提交前先向 k 展示变更摘要，经同意后提交（全局约定：不自动 commit）。

### 任务 2：logger.ts 配置函数 + main.ts 接入

- [ ] **步骤 1：创建 `src/utils/logger.ts`**

完整文件内容：

```ts
/**
 * 详细日志:把 console 输出持久化到设备文件,供事后排查。
 * AutoJs6 文档: console.setGlobalLogConfig / console.resetGlobalLogConfig / files.path / files.ensureDir
 */
export function setupDetailLog(enabled: boolean): string | null {
  if (!enabled) {
    console.resetGlobalLogConfig()
    return null
  }
  var 日志目录 = files.path('./logs')
  files.ensureDir(日志目录)
  var d = new Date()
  var pad = function (n: number) { return n < 10 ? '0' + n : '' + n }
  var 日志文件 = 日志目录 + '/运行日志-' + d.getFullYear() + pad(d.getMonth() + 1) + pad(d.getDate()) + '.log'
  console.setGlobalLogConfig({
    file: 日志文件,
    maxFileSize: 512 << 10,
    maxBackupSize: 5,
    immediateFlush: true,
  })
  log('[日志] 详细日志已开启: ' + 日志文件)
  return 日志文件
}
```

要点（诚实标注不确定项）：
- `console.setGlobalLogConfig` / `resetGlobalLogConfig` 声明见 `declarations/autojs6/aj6-int-console.d.ts:240/242`，文档名 "Configuration of saving Auto.js logs to local storage"
- `files.path` / `files.ensureDir` 声明见 `declarations/autojs6/aj6-int-files.d.ts:515/196`
- `files.path('./logs')` 的实际解析目录**未验证**（预期为脚本工作目录下 `logs/`，诊断脚本会打印确认）
- 输出文件名按日期：同一天多次运行追加同一文件；超 512KB 由 log4j 自动滚动保留 5 个备份

```ts
// test/详细日志诊断.ts — 诊断"详细日志"开关的落盘行为
// 运行:AutoJs6 打开 dist/详细日志诊断.js 执行,把日志贴回给 Claude
// 预期:开启后日志文件生成且含 MARK-A 标记;关闭后文件长度不再变化
import { setupDetailLog } from '../src/utils/logger'

log('===== 详细日志诊断开始 =====')
log('[诊断] files.cwd() = ' + files.cwd())

// 1. 开启:应生成文件,且配置之后的日志写入文件
var 文件 = setupDetailLog(true)
log('[诊断] setupDetailLog(true) 返回: ' + 文件)
if (!文件) {
  log('[诊断] ❌ 失败:返回 null')
} else {
  log('[诊断] 文件存在: ' + files.exists(文件))
  log('MARK-A-' + Date.now())
  sleep(1500)
  var 内容 = files.read(文件)
  log('[诊断] 开启后文件长度: ' + 内容.length)
  log('[诊断] 含 MARK-A 标记(应为 true): ' + (内容.indexOf('MARK-A-') >= 0))

  // 2. 关闭:再写日志不得进入文件
  setupDetailLog(false)
  var 长度前 = files.read(文件).length
  log('MARK-B-' + Date.now())
  sleep(1500)
  var 长度后 = files.read(文件).length
  log('[诊断] 关闭后写入前长度: ' + 长度前)
  log('[诊断] 关闭后写入后长度: ' + 长度后)
  log('[诊断] 已停止写入(应为 true): ' + (长度前 === 长度后))
}
log('===== 详细日志诊断结束 =====')
```
