# 图片路径集中管理 实现计划

> **面向 AI 代理的工作者：** 必需子技能：使用 superpowers:subagent-driven-development（推荐）或 superpowers:executing-plans 逐任务实现此计划。步骤使用复选框（`- [ ]`）语法来跟踪进度。

**目标：** 把散落在约 50 个文件中的 289 处硬编码图片路径字符串，收敛为「跨页共用图进 `src/images.ts` 共享表 + 每文件头部 IMG 映射」两级结构，重裁图片时改一处全生效。

**架构：** 新增 `src/images.ts` 导出 `sharedImages`（33 张跨文件引用 + `$` 前缀通用按钮图）；每个引用图片的文件头部定义 `const IMG = { ...sharedImages, 页面私有键: 'images/...' }`；文件内所有 `'images/...'` 字面量替换为 `IMG.xxx`。纯常量提取，无逻辑改动。

**技术栈：** TypeScript（ES5/Rhino 兼容，禁用箭头函数/const 解构——沿用现有风格）、webpack。

**迁移顺序：** 任务 1 建共享表 → 任务 2-5 迁移 utils/model 四个文件 → 任务 6-7 迁移两个大页面 → 任务 8 批量迁移 40 个小文件 → 任务 9 最终验证。

**验证命令（每任务通用）：** `npm run build` 必须通过。全部完成后的残留检查见任务 9。
