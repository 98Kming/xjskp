# 拟态牌库 / 机械震荡 日常任务 实现计划

> **面向 AI 代理的工作者：** 必需子技能：使用 superpowers:subagent-driven-development（推荐）或 superpowers:executing-plans 逐任务实现此计划。步骤使用复选框（`- [ ]`）语法来跟踪进度。

**目标：** 为「拟态牌库」「机械震荡」两个游戏内活动新增日常任务：进战斗页活动列表 → 点入口进活动页 → 点通用「任务」按钮 → 一键领取。

**架构：** 与现有 `src/pages/天空秘境.ts` 完全同构——每个活动一个 `BasePage` 子类（识别图 + `$任务` 路由 action），实例统一在 `src/model/pages.ts` 注册，任务并入 `src/model/daily.ts` 的「战斗页活动批量」流程（一次滚动扫描做完所有战斗页活动）。

**技术栈：** TypeScript + Webpack 5 + ts-loader，目标运行时 AutoX.js（Rhino，ES5）。

**规格：** [docs/superpowers/specs/2026-09-22-拟态牌库-机械震荡-design.md](../specs/2026-09-22-拟态牌库-机械震荡-design.md)

**关于测试：** 本计划不含单元测试。页面代码是纯图片识别 + 固定导航，无可分支逻辑；用户已决策用真机跑日常验证（见规格「测试」节）。每个任务用 `npm run build` 做编译验证，最后一个任务做真机验证。

**关于 commit：** 用户规则要求不自动提交。每个任务末尾只做验证，全部完成并经用户确认后再统一提交。
