# 观影签到日常任务 实现计划

> **面向 AI 代理的工作者：** 必需子技能：使用 superpowers:subagent-driven-development（推荐）或 superpowers:executing-plans 逐任务实现此计划。步骤使用复选框（`- [ ]`）语法来跟踪进度。

**目标：** 日常任务接入观影签到活动：2 个开关 + 2 个任务（签到、观影便利店免费领入场券）。

**架构：** 页面对象与路由已就绪（`src/pages/观影签到.ts`、`src/pages/观影便利店.ts`、战斗→观影签到路由），本次只做接入：layout.xml 加开关、MainWindow.ts 加类型、daily.ts 加 import/实例/任务。沿用「缘聚七夕」模式（活动页面每功能一个开关，`isDailyEnabled` + `doTask` + `nav()`）。

**技术栈：** AutoJs6 TypeScript（ES5 输出、Rhino 兼容），Webpack 构建 `npm run build`。

**规格：** [2026-08-18-观影签到日常任务-design.md](../../superpowers/specs/2026-08-18-观影签到日常任务-design.md)

**注意：** 本仓库无单元测试框架，验证方式是编译通过 + 真机运行。daily.ts 遵循 ES5 风格（`var`/`function`，禁箭头函数/const/解构）。

- [ ] **步骤 3：添加 2 个任务**

在第 236 行 `// ======== 基地（入口：历练大厅、食堂） ========` 注释之前插入：

```ts
  // ======== 观影签到（限时活动：签到、观影便利店） ========
  if (isDailyEnabled('观影签到_签到')) {
    doTask('观影签到 签到', function (): boolean {
      if (!nav(观影签到)) return false
      return 观影签到Page.免费领取()
    })
  }
  if (isDailyEnabled('观影签到_观影便利店')) {
    doTask('观影便利店 免费', function (): boolean {
      if (!nav(观影签到)) return false
      if (!nav(观影便利店)) return false
      return 观影便利店Page.免费()
    })
  }
```
